# Paper: "Sum Instead of And"

ICLR-style draft (anonymous). Main text is 9 pages including the conclusion; the appendix has the proofs, experimental details and extra tables.

- `latex/main.tex`, `latex/appendix.tex`, `latex/refs.bib`: sources (ICLR 2027 template files included)
- `latex/main.pdf`: compiled draft
- `latex/figs/`, `latex/tables/`: generated by `make_paper_assets.py`

## Reproduce

```bash
python theory/theory_checks.py                      # composite-null table (C3)
python paper/paper_synth.py                         # synthetic S1-S4, about 30 min on 2 CPU cores
for s in 0 1 2; do python run_toy.py --seed $s --out results/paper_toy/seed$s; done   # toy replica, 3 seeds
python paper/make_paper_assets.py --out paper/latex # figure + tables
cd paper/latex && latexmk -pdf main.tex
```

Real-data numbers (LBNL FCU/AHU, one seed each) are copied into `make_paper_assets.py` and `main.tex` from the `REPORT.md` files of the real-data runs (`run_real.py`).
